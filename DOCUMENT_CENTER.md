# Центр документов

Публичные адреса:

- `/documents` — основной Центр документов;
- `/sveden/documents` — прежний официальный адрес сохранён и показывает тот же каталог.

## Возможности

- категории документов;
- реквизиты: дата, номер, описание;
- поиск по названию, описанию, номеру, категории и версиям;
- фильтр по категории и диапазону дат;
- пагинация;
- история редакций;
- отдельный файл для каждой версии;
- отметка текущей версии;
- публикация/скрытие отдельных версий;
- примечание «что изменилось»;
- безопасное сохранение старых файлов в медиатеке.

При первой миграции существующий файл каждого документа автоматически переносится в историю и помечается текущей версией.

## Развёртывание

После `git pull`:

```bash
php artisan migrate --force
php artisan db:seed --class=OfficialDocumentCategoriesSeeder
php artisan optimize:clear
```

`npm` не требуется: стили уже добавлены в готовый файл `public/build`.

Seeder добавляет недостающие базовые категории и не удаляет существующие:
учредительные документы, лицензии и аккредитация, локальные акты, приказы, положения,
образовательные программы, документы о приёме, платные услуги, финансово-хозяйственная
деятельность, доступная среда и иные документы.

## Работа с версиями

В админке откройте **Центр документов**. В карточке документа блок **История редакций**
показывает все файлы. Через **Добавить новую версию** выбирается новый файл из медиатеки,
номер версии, дата редакции и описание изменений. Флаг **Сделать текущей** переключает
файл, который посетители получают по основной кнопке «Открыть документ».

Удаление записи версии не удаляет физический файл из медиатеки.
