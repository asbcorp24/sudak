# PWA-уведомления и кабинет студента

Frontend уже опубликован в `public/build`. **npm на сервере не нужен.**

После `git pull`:

```bash
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan pwa:vapid
```

Команда `pwa:vapid` выведет три строки. Добавьте их в production `.env`:

```env
WEBPUSH_PUBLIC_KEY=...
WEBPUSH_PRIVATE_KEY=...
WEBPUSH_SUBJECT=https://sudak.specdpo.ru
```

Затем:

```bash
php artisan optimize:clear
```

Для автоматических напоминаний и отложенных новостей Laravel Scheduler должен запускаться каждую минуту:

```cron
* * * * * cd /path/to/sudak && php artisan schedule:run >> /dev/null 2>&1
```

Web Push работает только в защищённом контексте HTTPS (кроме localhost). Пользователь включает уведомления сам кнопкой в личном кабинете.

## Что отправляется

- изменение расписания — студентам соответствующей учебной группы;
- публикация новости — всем студентам, у которых включена категория «Новости»;
- открытие регистрации на мероприятие — всем студентам;
- изменение даты/времени/места мероприятия — уже зарегистрированным участникам;
- отмена мероприятия — зарегистрированным участникам;
- напоминание «Завтра мероприятие» — зарегистрированным участникам в 09:00;
- подтверждение регистрации — самому студенту.

Все сообщения дополнительно сохраняются во внутреннем центре уведомлений кабинета.
