# Зеленодольский судостроительный колледж — официальный сайт

Технологичный сайт ГАПОУ «Зеленодольский судостроительный колледж» на Laravel 9, Bootstrap 5, Three.js и GSAP.

## Стек
- PHP 8.0.2+
- Laravel 9
- MySQL / MariaDB
- Bootstrap 5
- Three.js
- GSAP
- Vite

## Реализовано
- high-tech главная с процедурной 3D-сценой цифровой верфи;
- отдельная анимированная Three.js-сцена для каждой специальности;
- динамическая CMS: разделы → подразделы → страницы любой глубины;
- рекурсивное меню;
- новости;
- каталог специальностей;
- раздел «Сведения об образовательной организации»;
- адаптивный интерфейс;
- SEO-поля страниц;
- административная панель;
- настройка цвета и 3D-пресета специальности из CMS.

## 3D-пресеты
- `shipyard` — цифровая верфь;
- `shipbuilding` — корпус судна и шпангоуты;
- `engine` — судовой механизм;
- `electro` — электрические цепи и импульсы;
- `network` — сеть узлов и пакеты данных;
- `cnc` — цифровая механообработка;
- `quality` — 3D-сканирование и контроль качества;
- `blueprint` — инженерная чертёжная среда.

## Установка
```bash
composer install
cp .env.example .env
php artisan key:generate
```

Создайте базу данных, заполните параметры DB в `.env`, а также задайте собственные `ADMIN_EMAIL` и `ADMIN_PASSWORD`.

Затем:

```bash
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

Готовые frontend-файлы уже лежат в `public/build`. Node.js и npm на сервере не требуются.

Сайт: `http://127.0.0.1:8000`

Админка: `http://127.0.0.1:8000/admin`

## CMS
В разделе «Разделы и страницы» можно создавать верхнеуровневые разделы, подразделы и вложенные страницы любой глубины, управлять меню, публикацией и SEO.

## Специальности
Первичное наполнение соответствует опубликованной приёмной информации колледжа на 2026–2027 учебный год. Документы, контрольные цифры приёма и ежегодно меняющиеся сведения перед боевым запуском следует подтвердить у администрации колледжа.

## Безопасность
Пароль администратора не хранится в репозитории. Перед выполнением `php artisan db:seed` обязательно задайте `ADMIN_PASSWORD` в локальном `.env`.
