# Зеленодольский судостроительный колледж — официальный сайт

Технологичный сайт ГАПОУ «Зеленодольский судостроительный колледж» на Laravel 9, Bootstrap 5, Three.js и GSAP.

## Стек
- PHP 8.0.2+
- Laravel 9
- MySQL / MariaDB
- Bootstrap 5
- Three.js
- GSAP
- Vite

## Возможности
- динамическое меню: разделы → подразделы → страницы;
- CMS для самостоятельного создания и редактирования страниц;
- новости;
- каталог специальностей;
- раздел «Сведения об образовательной организации»;
- адаптивный интерфейс;
- версия для слабовидящих;
- high-tech 3D-главная на Three.js;
- SEO-поля страниц;
- административная панель.

## Установка
```bash
composer install
cp .env.example .env
php artisan key:generate
# настройте подключение к БД в .env
php artisan migrate --seed
npm install
npm run build
php artisan serve
```

После сидирования:
- Админка: `/admin`
- Логин: `admin@zsk.local`
- Пароль: `ChangeMe123!`

Перед публикацией обязательно измените пароль администратора и актуализируйте документы/приёмную кампанию.

## Контент
Первичное наполнение основано на открытых данных портала «Электронное образование Республики Татарстан». Контент в БД можно заменить через админ-панель без изменения кода.
